# agent-loop

Topic: an AI agent is a loop (model picks tool, result goes back, repeat), four common parts, and why a step limit matters.

Narration:
An AI agent isn't magic. It's a loop.
The model reads your goal, and picks a tool.
The tool runs, and the result goes back in.
Then it decides again, until it's done.
Four common parts: model, instructions, tools, memory.
Forget a step limit, and it can loop on and on.
