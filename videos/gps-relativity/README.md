# GPS Relativity

Topic: your phone GPS needs Einstein; satellite clocks run fast, so uncorrected GPS would drift about 10 km a day.
Style: diagram (map pin drift, two clocks, orbit, light-speed pulses). 1080x1920, 24.6 s.

## Script
Without Einstein, your phone's GPS would drift about ten kilometres off every day.
You'd think clocks tick the same everywhere, but they don't.
Satellites orbit 20,000 kilometres up, where gravity is weaker, so their clocks run fast.
The net gain is 38 millionths of a second a day.
Tiny, but GPS times radio signals moving at light speed, so that error adds up.
Next time you open maps, thank relativity.
