# Sources

Opened: https://arxiv.org/abs/2005.11401 (Lewis et al., original RAG paper)
Opened: https://aws.amazon.com/what-is/retrieval-augmented-generation/

1. "Answers come from memory" — arXiv: pre-trained models store knowledge in parameters; RAG pairs this with retrieval: "models which combine pre-trained parametric and non-parametric memory for language generation."
2. "RAG lets the model look things up first" — arXiv: "the non-parametric memory is a dense vector index of Wikipedia, accessed with a pre-trained neural retriever."
3. Name — Lewis et al. paper title: "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks"; AWS page is titled "What is RAG (Retrieval-Augmented Generation)?"
4. Search of outside knowledge base — AWS: the model "references an authoritative knowledge base outside of its training data sources."
5. Question + info given to model — AWS: "The user query and the relevant information are both given to the LLM."
6. No retraining — AWS: RAG is "a more cost-effective approach to introducing new data to the LLM."
7. Cite sources — AWS: RAG "allows the LLM to present accurate information with source attribution."
8. "Beats guessing" is opinion/point of view; arXiv notes that "providing provenance for their decisions and updating their world knowledge remain open research problems" for standard models.
