# Sources
Claims: a network is layers of simple units; connections carry weights; the signal flows forward (forward pass) to an output; output is compared with the target to give an error (loss); weights are nudged (gradient descent / backpropagation) to reduce the error; repeated over many examples.
- KDnuggets, "Neural Network Foundations, Explained: Updating Weights with Gradient Descent & Backpropagation" https://www.kdnuggets.com/2017/10/neural-network-foundations-explained-gradient-descent.html (fetched: weights on connections, forward passes, error = actual vs predicted, weights adjusted to reduce it)
- 3Blue1Brown, "What is backpropagation really doing?" https://www.3blue1brown.com/lessons/backpropagation (fetched: opens; explains backpropagation as how a network computes the gradient used to adjust weights)
No numbers are stated in the video. The 3-4-2 layer sizes are illustrative.
